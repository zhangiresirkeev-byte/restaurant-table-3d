# BeHere — интерактивный 3D-макет

## Открыть макет

**[▶ Запустить BeHere в браузере](https://zhangiresirkeev-byte.github.io/restaurant-table-3d/)**

Сайт уже размещён на GitHub Pages. Для просмотра не нужны аккаунт GitHub, установка программ или запуск своего сервера. Откройте ссылку, дождитесь загрузки модели и нажмите **«Показ за 30 секунд»**. Во время анимации интерфейс скрывается; Escape прерывает показ.

Можно свободно вращать модель, приближать устройство, открывать четыре ящика и переключать экраны BeHere. Для 3D-просмотра нужен браузер с поддержкой WebGL.

Квадратный стол на четыре места, центральное устройство и четыре боковых ящика для телефонов. Тёплый свет окна, полированный каменный пол, отражения, фактура ореха и чёрная обивка.

Перетаскивание вращает камеру, колесо приближает модель. Кнопки открывают ящики, показывают устройство крупно и возвращают исходный ракурс.

## Локальный запуск

`python -m http.server 8000` — затем открыть `http://localhost:8000/`.

## Разместить собственную копию

Если хотите свой адрес сайта: создайте Fork этого репозитория. В своём репозитории откройте Settings → Pages, выберите Deploy from a branch, ветку main и папку / (root), затем Save. После завершения сборки GitHub покажет ссылку на ваш сайт. Все пути к модели и текстурам относительные, поэтому копия работает в подпапке репозитория.

## Материалы и ограничения

Сцена использует настоящую геометрию и WebGL, а не фотографию в качестве фона. Текстуры продукта и процедурные материалы — 2096×2096. Свет и отражения рассчитаны для интерактивного браузерного просмотра; они визуально приближают фотографический ориентир. Это визуальный макет: электроника и конструкция ещё не испытаны.
