# Restaurant table — interactive 3D concept

Квадратный стол на четыре места, центральное устройство и четыре боковых ящика для телефонов. Тёплый свет окна, полированный каменный пол, отражения, фактура ореха и чёрная обивка.

Перетаскивание вращает камеру, колесо приближает модель. Кнопки открывают ящики, показывают устройство крупно и возвращают исходный ракурс.

## Локальный запуск

`python -m http.server 8000` — затем открыть `http://localhost:8000/`.

## GitHub Pages

В Settings → Pages выбрать Deploy from a branch, ветку main и папку / (root). Веб-сцена работает из подпапки репозитория: все пути относительные.

## Материалы и ограничения

Сцена использует настоящую геометрию и WebGL, а не фотографию в качестве фона. Текстуры продукта и процедурные материалы — 2096×2096. Свет и отражения рассчитаны для интерактивного браузерного просмотра; они визуально приближают фотографический ориентир. Это визуальный макет: электроника и конструкция ещё не испытаны.
